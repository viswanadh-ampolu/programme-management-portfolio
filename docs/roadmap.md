# Roadmap — Orion

Two views of the same plan: a **Now / Next / Later** view for stakeholders who want
direction, and a **phased milestone** view for those who want dates.

## Now / Next / Later

### 🟢 Now (this quarter)
- Finish discovery & journey mapping (Product & UX)
- Lock target architecture and integration contracts (Engineering)
- Draft KYC/AML rule set and get first compliance review (Risk & Compliance)
- Baseline current onboarding metrics (all)

### 🟡 Next (next quarter)
- Build MVP digital journey + automated identity check
- Stand up decisioning engine (rules v1)
- Ops readiness assessment and training plan (Change & Adoption)
- Controlled pilot with one region / 500 customers

### 🔵 Later (6–12 months)
- Full automated KYC/AML with audit sign-off
- National rollout, decommission manual path
- Benefits realisation review and handover to BAU
