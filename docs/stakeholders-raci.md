## Engagement plan

| Stakeholder | Interest | Cadence | Channel |
|---|---|---|---|
| SRO / Sponsor | Benefits, funding, risk | Weekly 1:1 + monthly board | Call + board pack |
| Ops Director | Readiness, adoption, disruption | Fortnightly | Delivery review |
| Compliance Lead | Regulatory sign-off | Weekly | Embedded in squad |
| CFO | Spend vs budget | Monthly | Board pack (finance page) |
| Front-line ops | Day-to-day change | Monthly + at rollout | Champions network, demos |
| Customer panel | Journey usability | Each research round | Research sessions |

## RACI — key decisions & deliverables

**R** = Responsible (does it) · **A** = Accountable (owns outcome, one per row) ·
**C** = Consulted · **I** = Informed

| Activity | PgM | SRO | Eng Lead | Product Lead | Compliance | Ops Dir |
|---|:--:|:--:|:--:|:--:|:--:|:--:|
| Approve programme scope | R | **A** | C | C | C | C |
| Release funding (phase gates) | C | **A** | I | I | I | I |
| Journey & UX design | C | I | C | **A**/R | C | C |
| Target architecture | C | I | **A**/R | C | C | I |
| KYC/AML rules sign-off | C | I | C | I | **A**/R | I |
| Go/no-go for pilot | R | **A** | C | C | C | C |
| Ops readiness & training | C | I | I | C | I | **A**/R |
| Status reporting | **A**/R | I | C | C | C | C |

> One **Accountable** per row keeps decisions unambiguous — the single most common
> cause of programme drift is two people each assuming the other owns a decision.
